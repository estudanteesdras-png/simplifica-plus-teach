# Simplifica  Tech

Crie um aplicativo web moderno, responsivo e profissional chamado “Simplifica+ Tech”.

Utilize todos os documentos enviados como base principal para desenvolver o projeto. Priorize as informações presentes neles e mantenha consistência com o Simplifica+ Tech. Não altere a proposta principal nem invente funcionalidades que não estejam alinhadas ao projeto.

Caso haja conflito entre o prompt e os documentos, dê prioridade aos documentos.

OBJETIVO DO APP

O Simplifica+ Tech é uma plataforma educacional voltada para professores da educação básica, com foco em planejamento de aulas, criação de atividades adaptadas e apoio à educação inclusiva. O sistema deve ajudar o professor a economizar tempo, organizar materiais e encontrar conteúdos mais adequados para diferentes perfis de estudantes.



IDENTIDADE VISUAL

- Cores principais: azul escuro, azul médio, roxo moderno e branco.

- Estilo visual: tecnológico, limpo, elegante e acessível.

- Aparência de startup de educação.

- Interface intuitiva, com bom contraste, cantos arredondados e visual premium.

- Usar ícones modernos e elementos visuais suaves, sem poluição.



TELAS PRINCIPAIS



1) TELA INICIAL

Criar uma landing page bonita e impactante com:

- Logo do Simplifica+ Tech no topo

- Título forte: “Simplifique o planejamento docente com tecnologia e inclusão”

- Texto curto explicando a plataforma

- Botão principal “Comece agora”

- Botão secundário “Entrar”

- Seção com 3 destaques:

  - Planejamento de aulas

  - Atividades adaptadas

  - Biblioteca inclusiva



2) TELA “COMECE AGORA”

Ao clicar em “Comece agora”, levar para uma tela de apresentação rápida com:

- Explicação simples do que a plataforma faz

- Benefícios para professores

- Botão “Criar conta”

- Botão “Já tenho conta”

- Pequeno destaque visual com ícone de educação e tecnologia



3) TELA DE LOGIN

Criar uma tela de login limpa e moderna com:

- Campo de e-mail

- Campo de senha

- Botão “Entrar”

- Link “Esqueci minha senha”

- Botão “Criar conta”

- Texto curto de boas-vindas



4) DASHBOARD PRINCIPAL

Após login, mostrar uma página inicial para o professor com:

- Saudação: “Olá, professor(a)!”

- Cards com acesso rápido para:

  - Planejamento de aula

  - Criar atividade adaptada

  - Biblioteca de materiais

  - Histórico

  - Favoritos

- Um resumo com estatísticas simples:

  - atividades criadas

  - materiais salvos

  - avaliações recebidas

- Visual organizado e profissional



5) PLANEJAMENTO DE AULA

Criar uma área onde o professor possa preencher:

- Série/ano

- Disciplina

- Tema da aula

- Objetivo da aprendizagem

- Duração da aula

- Tipo de adaptação, se necessário



O sistema deve gerar uma sugestão de planejamento com:

- objetivos

- metodologia

- recursos

- avaliação

- observações do professor



6) CRIAR ATIVIDADE ADAPTADA

Criar uma tela onde o professor selecione:

- série

- disciplina

- conteúdo

- tipo de necessidade educacional:

  - TEA

  - TDAH

  - deficiência intelectual

  - deficiência visual

  - sem adaptação



Ao gerar a atividade, mostrar:

- enunciado

- passos da atividade

- versão adaptada

- sugestões de apoio visual

- opção para editar antes de salvar



7) BIBLIOTECA DE MATERIAIS

Criar uma biblioteca organizada com:

- filtros por disciplina

- filtros por série

- filtros por tipo de adaptação

- busca por palavra-chave



Cada material na biblioteca deve aparecer em formato de card com:

- título

- disciplina

- série

- breve descrição

- botão salvar

- botão abrir



8) SISTEMA DE AVALIAÇÃO DA BIBLIOTECA

Adicionar um sistema de feedback em cada material da biblioteca:

- avaliação de 0 a 5 estrelas

- campo para comentários

- botão enviar avaliação



Essas avaliações e comentários devem servir para aprender como os usuários preferem os materiais, ajudando a IA do sistema a melhorar sugestões futuras com base no feedback dos professores.



9) IA EDUCACIONAL

Criar uma área de inteligência artificial que:

- gere atividades

- sugira adaptações

- reorganize o conteúdo

- aprenda com as avaliações e comentários da biblioteca

- personalize melhor as próximas sugestões conforme o uso dos professores



Exibir mensagens como:

- “Analisando a necessidade da turma...”

- “Gerando atividade adaptada...”

- “Aprimorando sugestões com base nos feedbacks...”



10) PERFIL DO PROFESSOR

Criar uma página de perfil com:

- nome

- escola

- disciplina

- materiais salvos

- histórico de planejamentos

- avaliações feitas

- preferências de ensino



FUNCIONALIDADES EXTRAS

- Salvar rascunhos

- Favoritar materiais

- Exportar em PDF

- Interface mobile-friendly

- Menu lateral elegante

- Modo claro e modo escuro

- Animações suaves e discretas

- Área de mensagens/notificações



EXPERIÊNCIA DO USUÁRIO

A navegação precisa ser simples, rápida e intuitiva, pensando em professores com pouco tempo. O app deve transmitir confiança, inovação e praticidade.



IMPORTANTE

O resultado deve parecer um produto real pronto para testes, com aparência de startup educacional profissional, e não apenas um protótipo simples. Priorizar design premium, organização visual, clareza e usabilidade.
